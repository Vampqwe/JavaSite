🚀 Легкий веб-движок на Java

Добро пожаловать! Это стартовая страница вашего легкого веб-движка.

Текущие возможности:

  • ✅ Обслуживание статических файлов (HTML, CSS, JS, изображения)
  • ✅ Маршрутизация запросов (REST API)
  • ✅ Многопоточная обработка запросов
  • ✅ Логгирование событий
  • ✅ Возможность расширения через интерфейс RequestHandler

Архитектура позволяет легко "утяжелить" движок, добавив:

  • Поддержку сессий и куки
  • Шаблонизатор (например, Thymeleaf или FreeMarker)
  • Работу с базой данных (JDBC, JPA/Hibernate)
  • Аутентификацию и авторизацию
  • WebSocket для real-time общения
  • Кэширование и оптимизацию производительности
